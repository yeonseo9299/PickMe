# PickMe
### 프로젝트 설명  **「결정장애 탈출기」**는 일상생활에서 여러 가지 선택지 중 하나를 고르기 어려운 사람들을 위한 선택 도우미 서비스이다. 사용자가 음식, 쇼핑, 여가 등 원하는 선택지를 직접 등록하고 관리할 수 있으며, 결정하기 어려울 때 랜덤 선택 기능을 통해 하나의 선택지를 추천받을 수 있다. 또한 선택한 결과를 기록하여 이전에 어떤 선택을 했는지도 확인할 수 있도록 구성하였다.  복잡한 기능보다는 **선택지 등록 → 선택지 관리 → 랜덤 결정 → 결과 확인**의 간단한 흐름을 중심으로 제작하여 누구나 쉽게 사용할 수 있도록 하는 것을 목표로 하였다.
